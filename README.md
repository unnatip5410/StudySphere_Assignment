# StudySphere – Smart Student Productivity Hub

Assignment-ready static website inspired by a modern SaaS/portfolio layout, with original content and design.

## Files
- index.html
- css/style.css
- js/script.js
- assets/
- README.md

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For VS Code, you can use Live Server if installed.

## Features
- Responsive design
- Hero landing page
- Feature cards
- Interactive study planner
- Dark/light mode
- FAQ accordion
- Contact form demo
- Smooth navigation
- Mobile navigation menu
